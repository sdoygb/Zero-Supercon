# 全自动 R(T) 记录系统（单片机 ＋ USB ＋ PC 程序）

> 性质：硬件/软件方案｜日期：2026-11-23
> 配套：`tools/autolog.py`（PC 端，已带模拟自测）、`notes/2026-11-23_Ag-GO_实验方案.md`（实验主体）
> 目标：单片机每 0.5 s 采一次（T、Vp、Vn、I），USB 传电脑，Python 实时算 R、画图、存 CSV

---

## §0 架构

```
[样品四端] → [INA128/AD8420 放大] → [ADS1220 24-bit ADC]
[PT100]   → [MAX31865]        → [Arduino/ESP32] → USB → PC(autolog.py)
[换向继电器] ← MCU 控制            ↑
[加热电阻 + MOSFET] ← PWM ────────┘
```

**采样策略**：不控温——PC 全程记录，**只用升温段**的数据（液氮还在时样品恒在 77 K，无信息）。

**采样间隔的定法**：升温速率由热漏定，铜块 50 g 的 $P/(mC)$：

| 热漏 | 升温速率 | 全程（77→300 K） |
|:--|--:|--:|
| $0.5\ \mathrm W$ | $1.6\ \mathrm{K/min}$ | $143\ \mathrm{min}$ |
| $1\ \mathrm W$ | $3.1\ \mathrm{K/min}$ | $72\ \mathrm{min}$ |
| $2\ \mathrm W$ | $6.2\ \mathrm{K/min}$ | $36\ \mathrm{min}$ |

过渡宽按 $2\ \mathrm K$ 算，要 $20$–$40$ 个点跨过去 ⟹ $\Delta T\le0.05$–$0.1\ \mathrm K$；$3\ \mathrm{K/min}$ 下即 $\Delta t=1$–$2\ \mathrm s$。**热滞后（样品-温度计平衡约 1–2 s）也把下限卡在 0.5 s**——所以：

**取 $\Delta t=1\ \mathrm s$**（升温慢于 $1\ \mathrm{K/min}$ 取 2 s，快于 $10\ \mathrm{K/min}$ 取 0.5 s）；全程 $2\,000$–$8\,000$ 行。

**流程**：MCU 先在电流正向读一次 $V_p$，继电器换向后再读 $V_n$，串口发一行：

```
t_ms, T_K, Vp_uV, Vn_uV, I_mA
```

PC 端 $R=(V_p-V_n)/(2I)$（µV/mA = mΩ），自动扣热电势。

**为什么用 ADS1220 而不是 ADS1115**：ADS1115 在 ±256 mV 档的 LSB 是 7.8 µV、噪声 ~5 µV，刚好卡在判据上；ADS1220 的 24 位加 PGA 给到 0.1 µV，余量足。

## §2 单片机骨架（Arduino）

```cpp
#include <SPI.h>
#include <Adafruit_MAX31865.h>

Adafruit_MAX31865 thermo(10);          // CS
const int REV_PIN  = 7;                // 换向
const int HEAT_PIN = 9;                // 加热 PWM
const float I_MA   = 1.0;              // 回路电流（由限流电阻定）

void setup() {
  Serial.begin(115200);
  thermo.begin(MAX31865_2WIRE);        // PT100 两线够用
  pinMode(REV_PIN, OUTPUT); pinMode(HEAT_PIN, OUTPUT);
}

float readV_uV() { /* 读 ADS1220 差分，返回 µV（含增益换算） */ }

void loop() {
  digitalWrite(REV_PIN, LOW);  delay(40);
  float vp = readV_uV();
  digitalWrite(REV_PIN, HIGH); delay(40);
  float vn = readV_uV();
  float T = thermo.temperature(100.0, 430.0);   // PT100 参数
  Serial.print(millis()); Serial.print(',');
  Serial.print(T, 2);     Serial.print(',');
  Serial.print(vp, 1);    Serial.print(',');
  Serial.print(vn, 1);    Serial.print(',');
  Serial.println(I_MA, 2);
  digitalWrite(HEAT_PIN, HIGH);         // 恒功率加热（要 PID 就换占空比）
  delay(500);
  digitalWrite(HEAT_PIN, LOW);
}
```

**要点**：

1. **换向后等 40 ms 再读**——继电器与线路的 RC 要稳定；
2. **加热恒定功率**（1–2 W）给出慢升温；要恒温点就加 PID（MCU 内 10 行代码，或 PC 端发设定值）；
3. **电流要标定**：限流电阻用 1% 精度，电池电压用万用表量一次。

## §4 精度账

| 环节 | 误差 | 对 $R$ 的影响 |
|:--|:--|:--|
| ADS1220（PGA=128） | 0.1 µV/LSB，噪声 ~1 µV | 1 mA 时 ~1 mΩ |
| 热电势（40 ms 换向消除） | 剩 ~1 µV | ~1 mΩ |
| 电流标定（1% 电阻） | 1% | $R$ 的 1% 系统差 |
| PT100/MAX31865 | ±0.5 K | $T_c$ 的 0.5 K |
| 样品与温度计热滞后 | 升温 ≤1 K/min 时 <1 K | $T_c$ 偏移 <1 K |

**结论**：整套的 $R$ 分辨率 ~2 mΩ（1 mA），对 2 Ω 的膜就是 $10^{-3}$——比"万能表四线"（10 mΩ）好一个量级。

## §5 注意

1. **电流换向的继电器**在低温箱外，别让线圈发热影响样品；
2. **信号线用屏蔽线**，屏蔽层在 MCU 端单点接地；
3. **加热电阻**离样品 2–3 cm，靠铜块传热，避免局部温度梯度；
4. 若用 ESP32，可用 WiFi 直接发数据，省 USB 线。
