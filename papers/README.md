## 一条结论（指针）

在 Allen–Dynes 形式内，$T_c/\omega_{\log}<0.280$（$T_c/\omega_{\log}$ 随 $\lambda$ 单调增，上限在 $\lambda\to\infty$）。故常温（300 K）必要 $\omega_{\log}\ge1073\ \mathrm K$；把 1058 条常压材料放在 $(\lambda,\omega_{\log})$ 平面上，它们落在一个 $\ln\lambda$ 与 $\ln\omega_{\log}$ 相关 $-0.775$ 的楔形里，窗口在楔外。详见 [Zd003](Zd003_常温窗口：300K的必要条件与材料图谱.md)。
